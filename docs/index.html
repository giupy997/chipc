A processor that lives
inside a blockchain.

RH‑4 is a real 4‑bit CPU — 1,029 NAND gates and 79 flip‑flops, synthesised from Verilog. The contract does not emulate it. It evaluates every gate, every block.

The clock is not an oscillator. One block, one clock tick. Robinhood Chain closes a block every 100 ms, so the processor runs at 10 Hz.

1,029 NAND gates The only combinational primitive in the design. Inverters are NANDs with their inputs tied together.
79 flip‑flops 16×4 register file, 8‑bit PC, 4‑bit output port, carry, zero, halt.
1 storage slot 79 bits of architectural state fit in a single 256‑bit word. One SSTORE per cycle.
60,088 gas per cycle Measured, not estimated: 39,088 of execution plus the 21,000 base transaction cost.
18,192 bytes of bytecode All 1,029 gates unrolled into one contract, 6,384 bytes below the limit. No delegatecall split.
10 Hz clock One cycle per block. Nothing schedules it and nothing can stop it short of the chain stopping.

How it’s built

Nothing here is hand‑written assembly pretending to be hardware. The processor starts as Verilog and goes through a real synthesis toolchain.

  1. 1

    Verilog

    A 12‑bit instruction word, single‑cycle execution, our own ISA — not a clone of the 4004.

  2. 2

    yosys

    Synthesised down to a single combinational primitive: abc -g NAND, then leftover inverters folded into NANDs too.

  3. 3

    Topological sort

    Inside the EVM there is no propagation, only a sequence. The gates have to be ordered before they can be emitted.

  4. 4

    Yul codegen

    Each gate becomes one line: mstore(y, iszero(and(mload(a), mload(b)))). Flip‑flops become bits of a single state word.

  5. 5

    The chain

    tick() reads ROM[pc], evaluates the cone, latches the flops, writes one slot.

Three simulations have to agree

RTL simulation, gate‑level simulation of the synthesised netlist, and execution inside the EVM — cycle for cycle. The Solidity test suite does not check the contract against itself. It checks that the contract behaves like the hardware.

Instruction set

12‑bit words. Sixteen registers of four bits each, an 8‑bit program counter, 256 words of ROM. Every instruction completes in one block.

Nobody owns the clock

tick() is open to anyone, once per block. Whoever calls it pays the gas for that cycle and is written into the Cycle event as its sponsor. There is no privileged keeper and no scheduler — the processor advances because someone, somewhere, wanted it to.

The program running on it has no hlt, and cannot have one. If the RH‑4 ever halts it halts forever, so the loop is checked over 20,000 cycles against the synthesised netlist and 5,300 cycles inside the EVM before anything is deployed.

Prior art

The idea of putting a real gate‑level processor on a chain is not ours. It was done first on BNB Chain, clocked by that chain’s 0.45 s blocks at 2.22 Hz. RH‑4 is an independent design with its own ISA, its own netlist and its own toolchain, built for a chain whose blocks close in 100 ms. Credit where it’s due.
